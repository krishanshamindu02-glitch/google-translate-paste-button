# Quick Paste for Google Translate

Adds a convenient one-click **Paste** button inside the Google Translate text box. The button automatically hides when you type or paste text, and reappears when the box is cleared.

## How to Install (Chrome / Edge / Brave)
1. Click the green **<> Code** button above and select **Download ZIP**.
2. Extract (unzip) the downloaded folder to your computer.
3. Open Chrome and go to `chrome://extensions/`
4. Turn ON **Developer mode** (top-right corner).
5. Click **Load unpacked** (top-left corner) and select the extracted folder.
6. Go to [Google Translate](https://translate.google.com) and enjoy!
